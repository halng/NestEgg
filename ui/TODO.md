# UI TODO

## Current market baseline for the stock screener

### Core/common features (must-have)
- [ ] Global search with ticker/company autocomplete, recent searches, and quick symbol navigation
- [ ] Saved screener presets for common strategies such as value, growth, dividend, momentum, and quality
- [ ] Multi-factor filter builder covering fundamentals, technicals, price action, volume/liquidity, market cap, exchange, sector, and dividend metrics
- [ ] Flexible filter controls with min/max ranges, include/exclude lists, percentage thresholds, and reset/apply actions
- [ ] Customizable result table with sortable columns, column picker, pinned columns, and dense/comfortable layouts
- [ ] Mini charts in screener rows plus an expanded chart view with timeframe switching
- [ ] Side-by-side comparison flow for selected tickers across price, valuation, profitability, and growth metrics
- [ ] Company snapshot panel with business summary, key statistics, and quick links into deeper analysis
- [ ] Watchlists with add/remove, tags, notes, and portfolio-style favorites management
- [ ] Alerts UI for price levels, volume spikes, technical signals, and screener-match notifications
- [ ] News and catalyst feed connected to each ticker and screener result set
- [ ] Earnings, dividend, and corporate action calendar views
- [ ] Saved views and shareable screener URLs so users can reopen the same setup quickly
- [ ] Export options for CSV/Excel and copyable comparison snapshots
- [ ] Responsive mobile/tablet screener flow instead of desktop-only sidebar filtering

### Differentiating features (nice-to-have / competitive edge)
- [ ] Sector and exchange heatmaps plus basic market breadth indicators
- [ ] Ownership context for foreign ownership limits, insider transactions, and institutional activity where data is available
- [ ] Dark mode polish, keyboard shortcuts, and fast-loading empty/loading/error states
