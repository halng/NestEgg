# NestEgg Agent Skills

Reusable skill definitions for NestEgg AI agents. Each skill file captures guidelines, conventions, and checklists for a specific technical or process domain. Agents declare which skills they depend on in their frontmatter.

## Available Skills

|-------|------|-------------|

| Python / FastAPI | [python-fastapi.md](python-fastapi.md) | Python 3.12 + FastAPI patterns for analytics and data-intensive services |
| gRPC / Protobuf | [grpc-protobuf.md](grpc-protobuf.md) | Internal service communication via gRPC and Protocol Buffers |
| Kafka Events | [kafka-events.md](kafka-events.md) | Async event-driven patterns, topic naming, producer/consumer conventions |
| React Frontend | [react-frontend.md](react-frontend.md) | React Native and Next.js patterns, TypeScript, Tailwind CSS |
| Code Review | [code-review.md](code-review.md) | Review standards, checklist, and process |
| Testing | [testing.md](testing.md) | Unit, integration, and e2e testing strategy for Java and Python |
| Security | [security.md](security.md) | Auth, OWASP, secrets management, Keycloak integration |
| Architecture | [architecture.md](architecture.md) | DDD, microservices, event-driven, and data architecture principles |
| Database | [database.md](database.md) | PostgreSQL, ClickHouse, Redis, and OpenSearch design patterns |
| Observability | [observability.md](observability.md) | OpenTelemetry, Prometheus, Grafana, Loki, and structured logging |
